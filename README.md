# Smart-Hospital-Room-Monitoring-Using-ESP8266-and-KiwisIoT
Smart Hospital Room Monitoring using NodeMCU ESP8266, DHT11, MQ-135, and PIR sensors to monitor temperature, humidity, air quality, and room movement in real time through the KiwisIoT platform.
Smart Hospital Room Monitoring Using ESP8266 and KiwisIoT

About the Project

The Smart Hospital Room Monitoring System is designed to monitor environmental conditions inside a hospital room, including temperature, humidity, air quality, and movement. This project uses a NodeMCU ESP8266, DHT11 temperature and humidity sensor, MQ-135 air quality sensor, and PIR motion sensor to collect room condition data.

The ESP8266 collects sensor readings and transmits the data over Wi-Fi to the KiwisIoT platform. Users can monitor real-time temperature, humidity, air quality, and room movement status through the KiwisIoT dashboard, making it easier to observe changes in the hospital room environment remotely.

This project demonstrates how IoT technology can be used for hospital room environmental monitoring, indoor air quality tracking, and smart healthcare facility monitoring.
